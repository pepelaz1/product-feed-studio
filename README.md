# Feed Studio

Локальный веб-конвертер товарного каталога на Node.js и SQLite. Принимает CSV с произвольными названиями колонок, предлагает сопоставление полей, проверяет данные и позволяет скачать YML-фид и очищенный CSV. В интерфейсе видны ошибки по строкам и история последних выгрузок.

## Запуск

Нужен Node.js 22.9 или новее. Внешние npm-пакеты не требуются.

```powershell
npm start
```

Откройте http://127.0.0.1:4174 и нажмите «Загрузить пример». Для проверки логики: `npm test`.

## Что проверяется

- Обязательные колонки: артикул, название, категория, цена, URL товара.
- Цена положительная, максимум два знака после запятой; ссылки начинаются с HTTP(S).
- Повторы артикула и некорректные строки попадают в отчёт и исключаются из экспорта.
- Поддерживаются CSV с запятой, точкой с запятой и табуляцией, кавычки и переносы строк внутри ячеек, UTF-8 и Windows-1251.
- Выгрузка содержит только валюту RUB. Поле наличия опционально.

Лимиты демо: CSV до 2 МБ и до 10 000 строк. Исходный CSV не сохраняется. SQLite-база с историей и сформированными файлами создаётся в `data/` и не попадает в Git.

## Границы примера

Это демонстрация базового цикла обработки каталога, а не готовая интеграция с маркетплейсом или CMS. Для реального магазина нужно согласовать схему исходных данных, требования конкретного получателя к YML, авторизацию, расписание обновлений и правила хранения данных. Демо запускается локально; публичный сервер без авторизации для загрузки чужих файлов не предусмотрен.
