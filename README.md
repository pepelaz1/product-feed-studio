# Feed Studio

Локальный веб-конвертер товарного каталога на Node.js и SQLite. Принимает CSV и XLSX с произвольными названиями колонок, находит начало таблицы, предлагает сопоставление полей и проверяет данные. Можно скачать очищенный CSV или XLSX без товарных ссылок либо дополнительно создать базовый YML-фид для Яндекс Маркета. В интерфейсе видны ошибки по строкам и история последних выгрузок.

## Запуск

Нужен Node.js 22.9 или новее. Установите зависимости один раз:

```powershell
npm ci
npm start
```

Откройте http://127.0.0.1:4174 и нажмите «Загрузить пример». Кнопка использует `sample/ready-catalog.csv`: пять демонстрационных товаров без ошибок. Рядом есть ссылки на образцы CSV и XLSX. В Excel-образце выберите лист «Товары»; первые две строки на нём служат примером вводной части прайса. `sample/catalog.csv` отдельно содержит две ошибочные строки для проверки диагностики. Для проверки логики: `npm test`.

## Что проверяется

- Обязательные колонки для очищенного CSV: артикул, название, категория и цена. Для YML дополнительно нужен URL товара.
- Строка заголовков ищется автоматически среди первых 30 строк. Если заголовки стоят в первой строке, ничего не пропускается. При необходимости номер строки можно изменить вручную.
- Цена положительная, максимум два знака после запятой; ссылки начинаются с HTTP(S).
- Повторы артикула и некорректные строки попадают в отчёт и исключаются из экспорта.
- Поддерживаются CSV с запятой, точкой с запятой и табуляцией, кавычки и переносы строк внутри ячеек, UTF-8 и Windows-1251. Для XLSX можно выбрать лист; формулы читаются по сохранённому в файле результату.
- Очистка выгружается в CSV и XLSX. В Excel цена остаётся числом, первая строка закреплена, а значения, похожие на формулы, сохраняются как текст.
- YML-выгрузка содержит цены в рублях, время в RFC 3339 с часовым поясом UTC, артикулы в `<offer id>`, категории, названия и необязательные описания, фотографии и остатки `<count>`.
- Несколько URL изображений можно перечислить через `;` в одной ячейке. Остаток, если выбран, должен быть целым неотрицательным числом.

Лимиты демо: CSV или XLSX до 2 МБ, до 10 000 строк и 100 колонок Excel. Исходный файл не сохраняется. SQLite-база с историей и сформированными файлами создаётся в `data/` и не попадает в Git.

## Границы примера

Это демонстрация базового цикла обработки каталога по [документации YML Маркета](https://yandex.ru/support/marketplace/ru/assortment/auto/yml), а не готовая интеграция с маркетплейсом или CMS. Выбран сценарий обновления каталога, не отдельный сценарий управления размещением DBS; поэтому атрибут `available` и элемент `<currencyId>` для DBS не выводятся. Для реального магазина нужно согласовать схему исходных данных, дополнительные обязательные характеристики конкретной категории, проверить созданный файл в кабинете продавца, настроить авторизацию и расписание обновлений. CSV-режим не создаёт YML и не требует данных магазина. Ссылки `example.com` в демонстрационном CSV вымышлены, и этот файл нельзя загрузить как действующий каталог. Демо запускается локально; публичный сервер без авторизации для загрузки чужих файлов не предусмотрен.
